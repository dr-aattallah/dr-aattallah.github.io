# Implementation Roadmap
## Stage 0 — LinkedIn (draft-first)
Inventory existing profile with owner-provided export/screenshots or authorized access. Produce headline, About, experience, skills, featured suggestions. Verify dates. Obtain approval before any edit.

## Stage 1 — Read-only website audit
Map HTML/CSS/JS and language switcher; inventory pages; record baseline screenshots; identify issues without editing production.

## Stage 2 — Roles and skills
Build AGENTS.md and role-specific checklists; define delegation and conflicts.

## Stage 3 — Quality gates
Automate HTML, JS, broken links, AR/EN RTL/LTR, responsive and accessibility checks.

## Stage 4 — Research registry
Record dated snapshots and verified publication identifiers; detect duplicates and conflicting records.

## Stage 5 — Operations
Generate change reports, review queues, rollback instructions; add scheduled jobs only after approval.

## Stage 6 — Optional orchestration
Implement executable agent workflows and private dashboard if technically justified and budgeted.

## First acceptance gate
Owner reviews Stage 0 drafts and Stage 1 audit before any website design changes or production releases.
