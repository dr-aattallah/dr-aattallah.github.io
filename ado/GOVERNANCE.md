# Governance and Release Policy
- GREEN: reading, inventory, audits, drafts, and tests may proceed without production modification.
- AMBER: create/change files in a dedicated branch; test and report before requesting approval.
- RED: merge, deploy, delete, change academic facts in public pages, or change account/security settings only with explicit owner authorization.
- Never publish research figures as live without live verification. Record platform, metric, snapshot date, source and confidence.
- Never expose credentials, tokens, private emails or authenticated account content in public repository.
- Preserve root site's bilingual RTL/LTR behavior and existing navy/gold visual identity.
- Do not touch `the-educator/` without separate explicit authorization.
- Design agent reference: https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md . Read upstream before implementation; use its interaction and accessibility principles without copying branding or replacing the current design.
- Release checklist: factual sources; AR/EN parity; desktop/mobile screenshots; accessibility; links; security; changelog; owner approval; rollback instructions.
