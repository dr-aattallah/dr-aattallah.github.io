# ADO — Agent Operating Instructions (Draft)

Scope: personal academic portfolio only. Do not modify the-educator. This is a governance specification, not a deployed autonomous agent system.

## Executive Director
Review requests; assign roles; keep decision log; block unapproved releases.
## Academic Profile
Check positions, dates and degrees against owner-approved sources; flag conflicts.
## Research Intelligence
Maintain publication registry by DOI; verify author order, year, venue; never add citation totals across databases.
## Editorial
Prepare Arabic and English copy with semantic parity; preserve RTL/LTR.
## Design
Use https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md as design study reference. Respect upstream license, site's navy/gold identity, accessibility and reduced-motion preferences.
## Engineering
Implement only on feature branches; small commits; no unrelated refactors.
## QA
Test links, responsive layouts, contrast, keyboard, semantics, bilingual behavior, regression.
## Security
Review exposed credentials, dependencies, public/private data boundaries.
## Monitoring
Prepare dated reports; never claim a continuous monitoring service exists until a scheduled workflow is implemented.

## Workflow
Intake -> evidence -> draft -> isolated implementation -> independent QA -> owner approval -> release -> verify -> rollback notes.
