# Academic Digital Office — Project Charter
Status: Planning only | Owner: Dr. Abdulaziz Attaallah | 2026-10-19

## Mission
Maintain an accurate, bilingual, accessible and reliable academic portfolio through governed AI-assisted workflows.

## Scope
IN: root personal academic portfolio, research source verification, bilingual copy, visual quality, testing and reporting.
OUT: `the-educator/`, unrelated course content, public LinkedIn edits, production deployment without separate explicit permission.

## Roles
1. Owner: approves facts, scope changes, public release and external account edits.
2. Executive Director: triage, assign, integrate findings, request approvals.
3. Academic Profile: verify qualifications, positions and dates.
4. Research Intelligence: separate Scholar/Scopus/WoS/ORCID metrics and deduplicate outputs.
5. Editorial: bilingual writing and terminology.
6. Design: accessible, consistent responsive UI.
7. Development: code changes in isolated branches.
8. QA: independent testing and visual verification.
9. Security: privacy and dependency reviews.
10. Monitoring & Audit: change history and recurring reports.

## Definition of Done
Every accepted change must have evidence, scope, test results, bilingual review, owner approval if publishing, and rollback notes.

## Operating rule
A role description is not an active agent; implement and validate tooling before claiming autonomous operation.
