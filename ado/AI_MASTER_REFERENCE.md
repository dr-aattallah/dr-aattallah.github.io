## Workflow
Request -> source verification -> task plan -> isolated branch -> implementation -> tests (desktop/tablet/mobile, Arabic/English, accessibility) -> independent review -> owner approval -> merge/deploy -> post-deployment verification.
Green: read/audit/report. Amber: edit feature branch only. Red: publish/delete/modify security or academic facts only after explicit owner approval.
Maintain provenance, dated evidence, changes, screenshots, and rollback instructions. Never commit secrets.
