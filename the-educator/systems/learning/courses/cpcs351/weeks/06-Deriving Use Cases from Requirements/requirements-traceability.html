Requirements–Use Case Traceability

Traceability shows which use cases satisfy each requirement and highlights gaps, unnecessary behavior, and priority.

7of 9 pages
Core lecture content Clarification & study aids
Learning focus

Use UML use-case notation and style to depict high-level user requirements and write use-case-centric functional specifications.

Core lecture

What you need to understand

  • Ask whether every requirement is covered by at least one use case and whether every use case has a requirement/business justification.
  • A traceability matrix maps requirements to use cases and can include priority/weight information.
  • Missing mappings can indicate missing use cases; use cases with no requirement may represent scope creep or undocumented needs.

Worked example

Library

R1 Check out documents → UC1 Check Out Document. R2 Return documents → UC2 Return Document. A “Share on Social Media” use case with no requirement should be questioned.

Remember

Traceability is the proof that the use-case model covers agreed requirements without unexplained scope.
