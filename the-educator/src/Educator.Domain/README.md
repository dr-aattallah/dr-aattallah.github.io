# Educator.Domain

Core business concepts for The Educator.

Current scope:

- Shared `Entity` base type
- Core `PlatformUser` domain model
- Core `Course` domain model
- Core `Enrollment` domain model
- Core `CourseResource` domain model
- First-pass domain enums for roles, statuses, visibility, and resource types

This project should not depend on ASP.NET Core, Supabase, database clients, or UI code.
