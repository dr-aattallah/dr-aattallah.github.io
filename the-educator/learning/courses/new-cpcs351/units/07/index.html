CONCEPT 1

Traceable change

Start with an issue and acceptance criteria, then create a small branch and implement a focused change.

ROOMNOWIssue: reject overlapping booking. Branch: feature/prevent-overlap; commit includes validation and tests.
Practice the engineering judgment

CONCEPT 2

Meaningful commits

Commits should capture understandable units of work and descriptive intent; commit count alone is not evidence.

ROOMNOW'Reject overlapping bookings' is more informative than 'updates'.

Pull requests

A PR presents purpose, changes, tests, risk and review questions before integration.

Peer review

Review behavior, maintainability, security and tests; give actionable feedback tied to evidence.

CONCEPT 5

Integration and refactoring

Integrate small changes frequently; refactor to improve internal design while preserving externally visible behavior.

APPLICATION · CLASS / PROJECT

Apply and transfer

Studio 4: in teams take one small issue through branch, change, PR, review and merge; Challenge 2 occurs separately in W10 M1.

Evidence standard: an understandable decision, a specific artifact or link where appropriate, a verification method, and a brief justification. Studios are formative; Challenges are individual graded work when scheduled.

Self-check (ungraded)

  1. State two concepts and distinguish their purposes.
  2. Explain one RoomNow design or workflow trade-off.
  3. Identify a defect or unsupported claim in a sample artifact.
  4. Suggest a correction and evidence that could validate it.
  5. Transfer the idea to a different system.
