Security Terms & User Security

Attack, Threat, Vulnerability, Identification, Authentication & Authorization

3of 7 pages

Common security terms

Attack

An attempt to breach system security.

Threat

A scenario that can harm a system.

Vulnerability

The “hole” that is used in the attack.

User Security

Identification

Identifying who you are, usually with a user ID or another unique code.

Authentication

Confirming that you truly are who you identify as, using keys, PINs, passwords or biometrics.

Authorization

Specifying or verifying how much access you have according to policy and configuration. The lecture highlights the Principle of Least Privilege.

Story checkpoint

The unlocked door analogy

An attacker wants patient data. A weak input-validation routine is the vulnerability—the opening. The possibility that someone may exploit it is the threat. The actual attempt to exploit it is the attack.

Try it · Least privilege

Should a receptionist automatically have the same access as a system administrator?

Reveal: No. Authorization should reflect the required role and the Principle of Least Privilege.
