Core lecture

What activity modeling covers

  • Complex information-processing activities and operations.
  • Information flow and object flow among activities.
  • Conditional branching according to decisions.
  • Forking, concurrency, joining, and synchronization.
  • Workflow among departments, classes, or subsystems.
Why use it?

Understand current work, then design better work

Activity modeling can describe processing in the existing organization to understand the business, then describe processing in the proposed solution during system design.

Use-case connection

Useful scope

Activity diagrams can describe a use case, a complicated method, or workflow spanning several use cases. Their particular strength is making parallel work visible.

Boundary

Do not use an activity diagram to explain how one object behaves over its lifetime. That is exactly where the state machine you just learned is stronger.
