Activity Modeling

Model workflows and transformational behavior: sequencing, decisions, object/information flow, concurrency, synchronization, and responsibility.

Learning focus

Core lecture

Where activity modeling fits

  • Object Interaction Modeling focuses on interactions among objects.
  • Object State Modeling addresses event-driven, state-dependent behavior.
  • Activity Modeling focuses on transformational systems with sequencing, conditional branching, concurrency, synchronization, and synchronous/asynchronous behavior.
  • Activity diagrams help understand flow of work performed by objects/components and can visualize relations across use cases.
  • They are especially strong at representing concurrent activities.
  • Activity modeling supports both analysis of current organizational processing and design of a proposed solution.
Choose the right model

Three behavioral questions

Sequence
Who communicates with whom, and in what order?
State
How does one object react over its lifetime?
Activity
How does work flow through actions and responsibilities?
