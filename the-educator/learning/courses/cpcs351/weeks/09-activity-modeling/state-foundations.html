Object State Modeling Foundations

Model the state-dependent reactions of an object to events or external stimuli.

2of 12 pages
Learning focus

Identify events, states, and state-dependent behavior from a requirement story.

Core lecture

What is object state modeling?

It is the identification, modeling, analysis, design, and specification of state-dependent reactions of objects to external stimuli.

  • What external stimuli or events matter?
  • What states can the object occupy?
  • How can we tell which state the object is in?
  • How does the reaction to an event depend on the current state?
  • How should complex states be represented and checked?
Simple intuition

The same event can mean different things

OFF— powerOn →ON— powerOff →OFF

The behavior is not just “what event occurred?” It is “what event occurred while the object was in which state?”

Basic definitions

Event and state

  • Event: a happening of interest or a request to a subsystem, object, or component.
  • State: a named abstraction of an object's condition or situation, entered or exited because of an event.
Diagnostic rule

If an object responds differently to the same request depending on its current condition, state modeling is probably valuable.

Think

Car example

An engine may be On/Off; a transmission may be Park/Reverse/Neutral/Forward; a brake may be Released/Applied. These are separate stateful concerns. Decide which object owns each state before drawing one giant diagram.
