Added examples

Five workflows to practice

  • Online shopping: browse/search → add to cart → checkout → authorize payment → prepare shipment → notify customer.
  • Food delivery: accept order → prepare food and locate courier concurrently → join for pickup → deliver → close order.
  • Clinic visit: check in → verify insurance and triage → consultation → optional tests → payment → discharge.
  • Software issue resolution: create ticket → reproduce issue → identify cause → implement fix → verify → close or reopen.
  • Document approval: author creates → reviewer accepts or requests changes → approver authorizes → owner archives.
  • Smart parking: request space → check availability → reserve → authorize payment → open gate → mark space occupied.
