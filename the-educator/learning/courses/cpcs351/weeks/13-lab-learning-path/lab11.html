Software Architecture Diagrams

Step up from classes and interactions to the organization of the whole software system. Explore packages, layers, client–server/N-tier organization, Pipe & Filter and MVC.

Architectural ideas

Client–server and layered/N-tier

A client requests services from a server. More complex web systems can separate user-interface, business/domain logic and database/technical-service concerns across layers or tiers.

Package Diagram

A high-level UML view that groups related classes and shows dependencies using dashed dependency arrows. Packages may contain nested subsystems and help designers understand major components.

Pipe & Filter

Organizes processing as a sequence of filters. Each filter transforms its input and passes the result through a pipe to the next stage. The source uses compilers and signal/speech processing as examples.

MVC

The supplementary calculator separates data/calculation logic (Model), user interface (View), and interaction coordination (Controller). The source includes Java Model, View, Controller and main-program code, then asks students to extend the calculator.

Architecture exercises

ATM package diagram
Model top-level ATMMain/ATMApplet, the atm package with ATM and Session, transaction subpackage, physical components and banking package; show dependencies and understand which parts are simulation-specific.
Room reservation architecture
Analyze a web-based single-room reservation system with calendar availability, recurring reservations, configurable constraints and reminder messages. Identify the system type, sketch an architecture and describe subsystem/component responsibilities. The source solution proposes N-tier architecture.
Online recruitment packages
Represent User Interface, Domain and Technical Service layers and their dependencies using a UML package diagram.
Pipe & Filter
Draw a simple compiler architecture and a signal-processing architecture using the pattern.
MVC extension
Starting from the supplied calculator code, extend functionality with subtraction, multiplication, division and power while preserving separation of Model, View and Controller.
