Lab 10 · Pattern Assessment

Applying Design Patterns

Demonstrate that you can select, apply and justify responsibility-assignment patterns in unfamiliar design situations rather than simply recognize their definitions.

AssessmentSingletonControllerExpertCreator
Learning focusApply design patterns and explain the resulting design improvement.
Required toolA UML-supporting modeling tool.
Evaluation lensCreation responsibility, information ownership, request handling, coupling and justification.

Five graded works

1 · Singleton structure
Draw the Singleton class diagram and explain how Singleton differs from a class whose methods are all static.
2 · Department-store sale
Analyze a Register, Sale and Payment design. Compare a version where Register does all the work with a version where Sale creates Payment; explain the improvements using Controller, Expert and Creator and discuss reduced coupling.
3 · Real applications
Give three realistic situations—not dummy examples—for Controller, Expert and Creator. The source points to banking/retail/email interfaces for Controller, authentication/reset-password for Expert, and diagram/modeling tools for Creator.
4 · Who should create the object?
Use the supplied model/figure and Creator reasoning to assign object-creation responsibility.
5 · Singleton candidates
Identify which classes in the UML Class Diagram Editor design could reasonably be singletons and justify the decision. The source solution identifies the Edit Class Diagram GUI and Controller because only one instance is needed.

Supporting creator examples

The source additionally asks who should create a Department when Faculty aggregates Department, and who should create other design objects based on the model. Use these examples to practice the central Creator question: which object has the strongest structural or lifecycle reason to create this object?

The lab repeats the three broad design-pattern categories—creational, structural and behavioral—to reinforce where Singleton and responsibility patterns fit in the larger pattern landscape.
