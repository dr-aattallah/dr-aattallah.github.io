Lab 08 · Behavioral Modeling Practice

Behavior Diagrams Assessment

Demonstrate that you can independently translate a narrative into the correct behavioral UML model after reviewing one example of each diagram type.

PracticeSequenceActivityState
Learning outcomeDepict behavioral UML diagrams: sequence, activity and state diagrams.
Assessment approachInstructor reviews an example, then students solve a same-type problem independently.
Source marksThree independent behavioral-modeling problems reinforce sequence, activity and state modeling.

Three independent practice problems

1 · Exam process → Sequence Diagram
Model notification, exam preparation/copying, distribution, student answering/submission, TA marking using sample solutions, mark recording and return of papers. Show actor participation, operations and arguments.
2 · Open Access Insurance → Activity Diagram
Model the workflow from customer insurance application, through agent requests for quotes, company responses, selection of the best policy, and delivery of proposal/quote to the customer.
3 · Luggage belt → State Diagram
Model a belt that starts when Start is pressed and stops when Stop is pressed or when no luggage has been detected for 60 seconds.

Review examples before assessment

ATM sequence

Trace card insertion, PIN entry, consortium/bank verification, service selection, withdrawal amount, bank approval, transaction confirmation, card ejection and cash dispensing.

Library checkout activity

Model library-card scanning, account/fine checking, required fine payment, asset scanning and the concurrent threads that later join.

Book state machine

Reason about “borrowable” and “not borrowable” states; the source example starts borrowable and transitions when the last copy is borrowed.

Project-related exercise: each group presents its Domain Class Diagram against design principles and receives feedback on missing or weak elements.
