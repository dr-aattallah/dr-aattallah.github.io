Why engineers model software

A model is an architectural or conceptual representation of a software system. It gives the team a higher-level view before implementation details dominate the discussion. Modeling helps stakeholders understand the system, supports decomposition into manageable modules, improves maintenance and testing, encourages reuse, and lets designers compare the proposed design with actual requirements before coding.

What UML adds

Unified Modeling Language is a standardized general-purpose modeling language used to specify, visualize and document software structure and behavior. It grew from object-oriented concepts such as classes and objects, but its notation can describe many kinds of systems and can be used throughout the software-development life cycle.

UML combines ideas from data, business/workflow, object and component modeling. UML 2.x organizes diagrams broadly into structural and behavioral families, with interaction diagrams forming an important behavioral subgroup.

UML tools and the working environment

A UML modeling tool supports UML notation and semantics. More advanced tools may generate source code from models and reconstruct models from source code; the latter is commonly called reverse engineering.

The source lab introduces tools including Rational Rose, Visual Paradigm, StarUML, ArgoUML, Edraw Max and Microsoft Visio. Its Visio walkthrough emphasizes the diagram canvas, Office-style ribbon and shape/stencil area; its Edraw walkthrough introduces File, Home, Insert, Page Layout, View, Symbols and Help menus.

Lab activities

Activity 1 · Banking Information System
Use a UML tool to draw the required Use Case Diagram for the provided banking scenario. Focus on identifying actors, system services and correct associations.
Activity 2 · Class Diagram
Reproduce the class-diagram exercise using a UML tool (the source specifically suggests Edraw for this activity). Pay attention to UML class notation and relationships.
Do not treat the tool as the learning objective. The objective is to express the software model correctly; the tool is the medium.
