Boundary Value Analysis

Focus tests where behavior is most likely to change: immediately around the boundaries between partitions.

6of 8 pages

The technique

Boundary Value Analysis is related to equivalence partitioning. The lecture says to test both sides of each boundary, assuming system behavior differs on opposite sides.

Lecture examples

Added example — course capacity 1–40

A compact boundary set is 0, 1, 40, 41. These values deliberately straddle the lower and upper boundaries rather than sampling random values such as 17 and 28.
