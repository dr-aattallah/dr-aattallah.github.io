Boundary Value Analysis

After Equivalence Partitioning finds the regions, Boundary Value Analysis targets the edges where software behavior is most likely to change.

EP → BVA

Find the regions. Then challenge their borders.

The lecture's rule is to test both sides of each boundary because behavior may differ immediately across the edge.

Date rule · 1 to 31

0just below lower boundary
1at valid lower boundary
31at valid upper boundary
32just above upper boundary

Username rule · 6 to 10 characters

5below lower
6valid lower
10valid upper
11above upper

Floating point · 0.2 to 0.8, one decimal place

0.1below lower
0.2valid lower
0.8valid upper
0.9above upper

More study examples

Exam score · 0–100Use −1, 0, 100, 101 to challenge the two edges.
Quantity · 1–5Use 0, 1, 5, 6. The middle value 3 is valid, but it does not challenge an edge.
Timeout · 10–30 secUse 9, 10, 30, 31. With decimals allowed, also consider precision around the boundary.
