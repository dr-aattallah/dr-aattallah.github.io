Lesson 08

Software Testing Review

Recognize the testing question first, then choose the appropriate level, method or black-box technique.

8of 8 pages

Retrieval practice

1. Tester sees only inputs and outputs.
Black-box testing.
2. Developer investigates branches and internal code logic.
White-box testing.
3. Username must be 6–10 chars. What are the EP regions?
Invalid 0–5, valid 6–10, invalid 11+.
4. What BVA values target the username rule?
5, 6, 10, 11.
5. Two independent Boolean conditions control an outcome. Useful technique?
Decision table testing; four combinations if both are True/False.
6. Maximum expected users vs beyond-limit abnormal load?
Load testing vs stress testing.
7. Finding a defect vs locating and fixing its cause?
Testing vs debugging.

One-minute map

Requirement/behavior → Black box. Internal logic → White box. Representative regions → EP. Edges → BVA. Combinations → Decision Table. Speed/capacity/stability/scalability → Performance.

Testing mindset

Do not choose test data randomly. Choose it because it represents a partition, challenges a boundary, covers a condition combination, or provides evidence for a stated requirement.
