03 · WHAT IS TESTED vs WHERE IT IS TESTED

Functional Testing & Testing Levels

Keep two ideas separate: the quality being evaluated and the scope of software under test.

Functional testing asks: “Does it do the required job?”

Functional testing is based on software specifications. Supply inputs, observe outputs, and compare the actual behavior with the functionality the system is intended to provide.

Identify functionality→Create test data→Define expected output→Execute test cases→Compare actual vs expected

Testing levels: zoom out through the system

●1 · UnitOne function, class, or component in isolation.
●●2 · IntegrationInteractions between combined units/components.
▦3 · SystemThe complete integrated system against system requirements.
✓4 · AcceptanceWhether the delivered system is acceptable for intended users/customer.
Unit→Integration→System→Acceptance
