Equivalence Partitioning

Reduce a huge input space into groups expected to behave equivalently, then choose representative test data.

5of 8 pages

The technique

Equivalence Partitioning is a test-design technique: divide input test data into partitions and test each partition once, based on the assumption that inputs inside the same partition produce equivalent behavior/output.

Lecture examples

Date 1–31
Invalid: ≤0 · Valid: 1–31 · Invalid: ≥32.
Username 6–10 chars
Invalid: 0–5 · Valid: 6–10 · Invalid: ≥11.
Age 18–80 except 60–65
Invalid: <18 · Valid: 18–59 · Invalid: 60–65 · Valid: 66–80 · Invalid: >80.
Try it

Username partition checker

Enter a username length.

The point is not to test every possible length; choose representatives from each distinct partition.

Exam habit

Write the valid and invalid partitions first. Only then choose representative values.
