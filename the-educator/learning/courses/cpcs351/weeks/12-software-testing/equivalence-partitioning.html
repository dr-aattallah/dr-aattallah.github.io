05 · BLACK-BOX TEST DESIGN

Equivalence Partitioning

Stop testing random values. Divide a large input domain into behavioral regions, then choose representatives from each region.

CORE IDEA

Many inputs → few meaningful partitions → representative tests

Inputs within one partition are assumed to produce equivalent behavior, so we deliberately sample the partitions rather than every possible value.

Example 1 · Date must be 1–31

Invalid
≤ 0
… −2, −1, 0
Valid
1–31
1, 2, … 31
Invalid
≥ 32
32, 33, …

Example 2 · Username must be 6–10 characters

Invalid
0–5 characters
Valid
6–10 characters
Invalid
11+ characters
Representative set: choose one value from each region, for example 3, 8, and 12. The goal is partition coverage, not exhaustive testing.

Example 3 · Age 18–80 except 60–65

Invalid <18→Valid 18–59→Invalid 60–65→Valid 66–80→Invalid >80

This example matters because valid/invalid regions do not have to form one continuous interval.
