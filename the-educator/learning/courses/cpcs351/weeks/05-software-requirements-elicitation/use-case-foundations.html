Use-Case Foundations

A use-case model asks: which external role wants what useful result from the system?

5of 9 pages
Core lecture content Clarification & study aids
Learning focus

Read and construct UML use-case diagrams using actors, use cases, system boundaries and relationships.

What the model captures

Goals, interactions and required behavior

  • A use-case diagram depicts a useful subset of the larger use-case model for communication.
  • A use-case model describes user goals, interactions with the system, and behavior required to satisfy those goals.
  • Core elements are actors, use cases, the system boundary and relationships.
  • Use cases support requirements communication, analysis/design discovery, and test identification.
