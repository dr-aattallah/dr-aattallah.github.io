Use-Case Foundations

Use cases provide an actor-centered view of functional requirements and create a bridge to analysis, design, and testing.

4of 9 pages
Core lecture content Clarification & study aids
Learning focus

Justify functional and non-functional requirements and apply elicitation/analysis methods to produce software requirements.

Core lecture

What you need to understand

  • A use-case diagram depicts a useful subset of the use-case model to simplify communication.
  • The model captures user goals, interactions with the system, and required system behavior.
  • Core elements are actors, use cases, system/subsystem boundary, and relationships.
  • Use cases can help requirements communication, analysis/design discovery, and test identification.
