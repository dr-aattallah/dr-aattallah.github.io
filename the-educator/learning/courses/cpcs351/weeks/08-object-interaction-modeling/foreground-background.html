Foreground vs Background Processing

The screen is only the visible edge of the use case.

🖥️

Actor–System Interaction

Foreground processing: acquiring actor input/action and displaying system responses.

⚙️

Object Interaction

Background processing: objects collaborate, high-level algorithms process requests, and system responses are produced.

Example: course registration

Student clicks Register
→
Controller retrieves student & section
→
Check prerequisites / capacity / conflicts
→
Create Enrollment
→
Show result

The first and last boxes are visible foreground behavior. The middle collaboration is the background behavior OIM is designed to expose.

Diagnostic question

If the GUI disappeared, what processing would still have to happen to satisfy the request? That is the interaction you are trying to model.
