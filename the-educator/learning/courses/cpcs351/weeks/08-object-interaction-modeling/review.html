Common Mistakes, Agile Guidance & Exam Checklist

A sequence diagram can look neat and still be semantically wrong.

Common mistakes from the lecture

✗ Merge separate calls into one activation

Four calls to DBMgr are four executions, not one continuous execution interval.

✗ Incorrect nesting

If calls happen during process(...), their execution must be nested within that control flow.

✗ Process before the trigger

getUser(uid) cannot happen before the Patron submits uid.

✗ Turn the diagram into code

OIM is high-level interaction design; omit unnecessary programming detail.

Agile principles

✓ Work closely with customers/users to understand business transactions.
✓ Write scenarios and scenario tables collaboratively.
✓ Skip an artifact when the team already understands the scenario well.
✓ Convert scenario/table to a sequence diagram off-line when visualization adds value.
✓ Keep it simple; prototype when needed to remove doubt.
