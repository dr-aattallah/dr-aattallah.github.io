Loops, Guards, Creation & Object Instances

Add control semantics only after the basic interaction order is correct.

🔁Loop

Repeat an interaction, e.g. for each call number.

🚦[guard]

Execute only when a condition is true, e.g. [d!=null].

✨create

Create a new object, e.g. l:Loan.

↩️Return

Communicate a value back to the caller when useful.

Library Checkout control story

loop [for each cn in callNumList]
d := DBMgr.getDocument(cn)
[d != null] a := d.isAvailable()
[a] create Loan(u,d)
[a] d.setAvailable(false)
[a] DBMgr.saveLoan(l); saveDocument(d)
