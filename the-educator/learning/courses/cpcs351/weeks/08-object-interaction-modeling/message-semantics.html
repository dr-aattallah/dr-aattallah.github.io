Lesson 09

Messages, Returns & Flow of Control

A design message can become a precise function call—not just an informal arrow label.

Read the message signature

msg := verify(uid:String, password:Password) : String
verify

Function/operation being called.

uid, password

Parameters.

String / Password

Parameter types.

msg : String

Return value and return type.

Correct causal order

1 · Patron → LoginGUI: uid, password
2 · LoginGUI → LoginController: verify(uid,password)
3 · LoginController → LoginGUI: msg
4 · LoginGUI → Patron: msg
Flow-of-control rule

The triggering event must occur before processing. Nested calls happen during the caller’s execution; separate calls require separate execution intervals.
