Worked Examples: Find the Collaboration

Different domains, same reasoning pattern: trigger → background objects → result.

🎮Fantasy Quest Reservation

Player → QuestUI → ReservationController → QuestInventory → Party → Reservation → confirmation.

🎓Course Registration

Student → RegistrationUI → Controller → Student/Section checks → Enrollment → result.

🛒Online Shopping

Customer → Storefront → Cart → Inventory → Order/Payment → confirmation.

🏥Clinic Appointment

Patient → AppointmentUI → Scheduler → ProviderAvailability → Appointment → confirmation.
