Learning focus

Choose among inheritance, association, aggregation, and composition using semantic tests rather than visual preference.

Relationship map

Strong whole–part

Study strategy: do not memorize the red labels as isolated symbols. Cover the labels and try to identify each notation from the diagram itself, then state what it means in the Library domain.

Lecture scope

Keep the domain model focused

The lecture notes that UML contains more relationship types, but for this domain-modeling material the focus is on inheritance, association, aggregation, and composition, with multiplicity and roles used to make associations precise.

Memory hook

IS-A → inheritance. PART-OF → aggregation/composition. Otherwise meaningful domain link → association.
