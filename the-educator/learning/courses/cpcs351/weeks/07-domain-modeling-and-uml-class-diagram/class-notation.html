UML Class Notation & Types

Read compact and expanded class notation and understand attribute, parameter, and return types.

5of 14
  • A UML class diagram is a structural diagram.
  • It can show classes, attributes, operations, and relationships; a domain model suppresses operations.
  • Compact view may show only the class name; expanded view separates name, attributes, and operations into compartments.
  • Attribute syntax: name : type, for example name : String.
  • Operation syntax may include parameter name/type and return type, e.g. checkIn(time : float) : void.
