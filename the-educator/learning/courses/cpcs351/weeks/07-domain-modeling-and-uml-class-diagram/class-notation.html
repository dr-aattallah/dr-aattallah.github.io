UML Class Notation & Types

Learn how UML writes a class, its attributes and operations—and what must be omitted when the diagram is a domain model.

5of 14
Learning focus

Read compact and expanded class notation and interpret attribute/operation type syntax.

Structural diagram

A UML class diagram shows structure

The lecture describes the UML class diagram as a structural diagram showing classes, their attributes and operations, and relationships between classes. For a domain model, show the classes, attributes and relationships—but omit operations.

Exam distinction

A full UML class diagram may contain operations. A domain model class diagram does not show operations because its purpose is conceptual understanding of the application domain.
