OO Foundations: Objects, Classes, Attributes & Operations

Connect real-world domain concepts to the object-oriented vocabulary used by UML.

4of 14
  • The OO paradigm views the real world as objects that relate to and interact with each other.
  • Objects are the basic building blocks and starting point.
  • A class is a type: an abstraction and intentional definition of objects with similar properties and behavior.
  • An attribute defines a property of a class of objects.
  • An operation defines behavior.
  • An object is an instance of a class.
  • Encapsulation stores properties and behavior together for a class/object.
