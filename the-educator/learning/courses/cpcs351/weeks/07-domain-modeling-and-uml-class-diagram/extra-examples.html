Practice method

For every example

  • Write 5–8 candidate concepts before drawing.
  • Separate objects/classes from attributes using independent existence.
  • Write each relationship as a sentence.
  • Choose inheritance, association, aggregation, or composition only after the sentence is clear.
  • Add multiplicities from business rules.
  • Remove operations if the goal is a domain model.
Remember

Practice domain rules and multiplicities before drawing lines.
