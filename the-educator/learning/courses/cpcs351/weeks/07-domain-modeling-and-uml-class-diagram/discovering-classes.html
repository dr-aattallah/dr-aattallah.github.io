Discovering Classes: Object or Attribute?

A noun phrase is not automatically a class. The real question is whether it has independent existence in the application domain.

6of 14
Learning focus

Apply the lecture rules for deciding whether a candidate noun/noun phrase should become a class or an attribute.

Decision hook

Ask: can it exist independently?

🏛️Independent existence?

If the concept can exist meaningfully on its own in the domain, it may be an object/class.

🏷️Describes something?

If it mainly describes another object or stores its state, it is probably an attribute.

⌨️Can you enter its value?

The lecture notes that attribute values can be entered directly, while objects must be created.

Lecture example

“Number of seats” — class or attribute?

✕ Treat it as a class

“Number of seats” has no independent existence. It only makes sense as the number of seats of a car, airplane, or classroom.

→

✓ Treat it as an attribute

numberOfSeats belongs to a class such as Car, Airplane, or Classroom.

Candidate triage

Classify noun phrases before drawing

Remember

Nouns generate candidates, not answers. Use independent existence and descriptive role to decide whether a candidate belongs as a class or an attribute.
