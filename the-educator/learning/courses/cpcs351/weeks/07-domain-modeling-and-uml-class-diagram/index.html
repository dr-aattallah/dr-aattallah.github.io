Core lecture

What domain modeling means

  • A model is a conceptual representation that lets a team communicate a shared perception of a piece of reality.
  • Domain modeling is a conceptualization process that helps the development team understand the application domain.
  • A domain model defines application-domain concepts using classes, attributes, and relationships.
  • It supports communication among team members and, in some cases, customers/users.
  • It provides a basis for design, implementation, and maintenance.
  • For domain modeling, represent the result as a UML class diagram without operations.
