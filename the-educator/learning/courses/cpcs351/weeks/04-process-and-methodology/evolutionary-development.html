Evolutionary Development

Do not build everything at once. Build something useful, learn from it, and let the real product grow.

6of 11 pages
Core lecture content Clarification & study aids
Learning focus

Explain how a working system evolves through successive versions, and distinguish evolutionary development from throwaway prototyping.

Core lecture · four anchors

Think of the product as something that grows

🌱

Start Small

The initial working version implements only a useful subset of the required capability.

👥

Use It

Real users evaluate working versions rather than reacting only to documents and plans.

💬

Learn

Feedback reveals what matters, what is missing, and what should change in the next version.

🚀

Grow

The working system itself evolves toward production instead of being thrown away after learning.

Critical distinction

Prototype or evolving product?

🗑️ Throwaway Prototyping

Build → learn → discard. The prototype primarily helps discover or clarify requirements.

🌳 Evolutionary Development

Build → learn → improve → keep. The working version grows into the production system.

🌱→🌳
Memory hook

Evolution means growth, not replacement. The seed you start with becomes the tree you eventually use.

Worked example

Research analytics tool

Version 0.1: upload a dataset and run one analysis. Version 0.5: add visualizations. Version 0.8: add collaboration and saved workflows. Production: automation, permissions, monitoring, and a hardened architecture. Scientists use every working release, and their feedback shapes what grows next.

Watch the trade-off

Evolutionary development is valuable in uncertain or exploratory domains, but uncontrolled growth can damage architecture and documentation. Evolution still needs engineering discipline.

Added clarification

Exam lens

Recognition clue

If a scenario says users repeatedly receive working versions and the same product grows over time, think evolutionary development.

Do not confuse it

If the early model is intentionally discarded after requirements are learned, that is throwaway prototyping, not evolutionary development.
