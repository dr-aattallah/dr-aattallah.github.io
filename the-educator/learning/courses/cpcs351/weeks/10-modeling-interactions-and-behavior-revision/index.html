A connected revision of the UML views used to describe structure, users, object interaction, state-dependent behaviour, and workflow.

Revision goal

Choose the correct UML diagram for a modeling question and explain what information each diagram communicates.

Core revision

Five UML diagram types

Class diagram
Object classes and associations; static structure.
Use case diagram
Interactions between the system and its environment; actors and tasks.
Sequence diagram
Interactions between actors/system and system components through ordered messages.
State diagram
How a system/object reacts to internal and external events.
Activity diagram
Activities involved in a process or data processing workflow.

The fastest way to choose

  • What exists and how is it related? → Class.
  • Who uses the system and for what goal? → Use case.
  • Who sends which message, and when? → Sequence.
  • What states can one object occupy and what events change them? → State.
  • What work happens next, conditionally, or in parallel? → Activity.

Remember

The diagrams are complementary views of the same system. Do not ask which diagram is “best”; ask which modeling question you need to answer.
