Evolutionary Development

Evolutionary development grows the actual working system through successive useful versions.

6of 11 pages
Core lecture content Clarification & study aids
Learning focus

Describe the different software development models: waterfall, prototype, evolutionary, spiral, and agile.

Core lecture

What you need to understand

  • An initial version implements a subset of the needed capability.
  • Users evaluate working versions and feedback shapes later versions.
  • The prototype/system evolves toward production rather than being discarded.
  • It suits exploratory or uncertain domains but can create architectural and documentation problems if growth is unmanaged.
