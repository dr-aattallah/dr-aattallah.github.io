Discovering Classes: Object or Attribute?

Use independent existence and state-description tests to avoid turning every noun into a class.

6of 14
  • A noun/noun phrase can be either a class or an attribute.
  • An object has independent existence in the application domain; an attribute does not.
  • Example from the lecture: “number of seats” is an attribute because it only makes sense as number of seats of a car, airplane, or classroom.
  • Attributes describe objects or store state information about objects.
  • You can enter an attribute value from the keyboard, but an object must be created as an object.
