System Engineering

Software often lives inside a larger system of hardware, people, procedures, and external services. System engineering coordinates the whole.

1of 8 pages
Core lecture content Clarification & study aids
Learning focus

Differentiate among the phases of software development and understand software engineering within broader system engineering.

Core lecture

What you need to understand

  • System engineering is a multidisciplinary approach covering the system life cycle.
  • It defines system requirements and constraints, allocates requirements to hardware, software, and human subsystems, and integrates them.
  • Software engineering is one part of system engineering.
  • Embedded and socio-technical systems depend on interactions among hardware, software, and human components.

Worked example

Airport Baggage Handling System (ABHS)

Check-in software, conveyors, scanners, staff procedures, flight information, and physical baggage flow must work as one system.

Remember

System engineering optimizes the whole system, not one subsystem in isolation.
