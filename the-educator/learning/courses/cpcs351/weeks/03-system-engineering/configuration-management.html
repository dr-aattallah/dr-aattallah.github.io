System Configuration Management

Configuration management keeps interdependent system components consistent as they change.

8of 8 pages
Core lecture content Clarification & study aids
Learning focus

Differentiate among the phases of software development and understand software engineering within broader system engineering.

Core lecture

What you need to understand

  • System components evolve at different times and may have compatibility dependencies.
  • Configuration management identifies versions, controls changes, and preserves consistent baselines.
  • Without coordinated versioning, individually correct components may form an incompatible system.

Worked example

ABHS release

Remember

Configuration management protects consistency across the evolving whole system.
