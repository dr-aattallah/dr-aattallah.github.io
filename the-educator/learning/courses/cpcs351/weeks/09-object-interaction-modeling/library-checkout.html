Library Checkout

  1. Patron submits call numbers.
  2. GUI asks controller to process.
  3. Controller retrieves each Document via DBMgr.
  4. Availability is checked.
  5. If available, Loan is created and Document state changes.
  6. Objects are saved.
  7. Result message returns to GUI and Patron.
