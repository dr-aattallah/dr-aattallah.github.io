Introduction to Software Engineering

Build the mental map first: software engineering coordinates development, quality assurance, and project management to improve productivity and quality while controlling cost and time.

1of 11 pages
Before You StartTwo teams can write equally good code. Why might one still fail to deliver a successful software system?

Use this question to separate “programming” from the broader engineering work around software.

Core lecture content Clarification & study aids
Learning Focus

By the end of this lesson, distinguish programming from software engineering and explain the PQCT goals and the three coordinated life-cycle tracks.

Core Lecture

What You Need to Understand

  • Software engineering aims to improve Productivity and Quality while reducing Cost and Time to market (PQCT).
  • Software engineering has three interacting life-cycle tracks: development, software quality assurance, and project management.
  • Object-oriented software engineering is a specialization that views systems as interacting objects.

Worked Example

Banking Platform

A banking team can produce correct code yet still fail if requirements are misunderstood, releases are poorly coordinated, risks are ignored, or quality evidence is missing. Software engineering manages the whole delivery system—not only the code.

Remember

Software engineering is coordinated engineering across the whole software life cycle.

Common Misconception

“Software engineering is just disciplined programming.” Programming is one development activity. Software engineering also includes requirements, modeling, quality assurance, coordination, risk, planning, deployment, and evolution.

Added Practice

Classify the Work

Scenario

A team is building a hospital appointment system. Classify each activity as mainly development, SQA, or project management: eliciting booking rules; reviewing requirements for ambiguity; estimating the release effort.

Self-Feedback

A strong answer is: development → elicitation; SQA → requirements review; project management → effort estimation. Explain why each activity belongs there.
