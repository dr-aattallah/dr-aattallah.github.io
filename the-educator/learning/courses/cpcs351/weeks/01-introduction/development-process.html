Software Development Process

The development process transforms a business need into a deployed system through connected activities whose outputs become inputs to later work.

7of 11 pages
Before You StartIf coding starts before the team agrees on the problem, what exactly is the code implementing?

Follow the chain from business need to operational system.

Core lecture content Clarification & study aids
Learning Focus

Order the major development activities and explain how a deliverable from one activity constrains or enables the next.

Core Lecture

From Need to Operational System

  • Identify business needs and assess feasibility.
  • Formulate requirements or capabilities the system must deliver.
  • Design the solution structure and behavior.
  • Implement the design in software.
  • Test the implementation against expected behavior.
  • Deploy the system into its target environment.
  • Artifacts from one activity become inputs to later activities.

Worked Example

Food-Delivery App

Need: reduce order-status uncertainty → requirement: customers see real-time order state → design: components and interactions for status updates → implementation → tests → deployment. Each step makes the next more concrete.

Remember

A development process is not a list of departments; it is a connected transformation from problem understanding to operational software.

Common Misconception

“Every process must execute these activities once in a strict one-way order.” The activities are fundamental, but different methodologies organize, repeat, overlap, or iterate them differently.

Added Practice

What Should Exist Before Coding?

Prompt

For a password-reset feature, name one useful deliverable from requirements and one from design before implementation begins.

Self-Feedback

A strong answer might identify required reset behavior/security constraints, then a designed interaction or component responsibility that implements those requirements.
