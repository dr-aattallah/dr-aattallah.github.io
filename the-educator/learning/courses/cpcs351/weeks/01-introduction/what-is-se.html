Topic 01 · Lesson 02

What Is Software Engineering?

Software engineering applies engineering processes and methods to improve the way software is produced and the quality of what is delivered.

2of 8 lessons
The engineering responseIf coding faster reduces time but damages quality, did the project really improve?
Learning Focus

Define software engineering using the chapter terminology and explain the four PQCT goals and their trade-offs.

Official Definition

Software Engineering as a Discipline

Software engineering focuses on the research, education, and application of engineering processes and methods to significantly increase software productivity and quality while reducing software cost and time to market.

Visual Anchor · PQCT Dashboard
P ↑Productivity
Q ↑Quality
C ↓Cost
T ↓Time to Market

The goal is not to optimize one number blindly. Engineering decisions balance all four pressures.

Worked Example

A Release Trade-off

A team can shorten time to market by skipping reviews and tests, but that may lower quality and increase later cost. Software engineering asks for a repeatable process that improves the overall PQCT outcome rather than one metric in isolation.

Make the Trade-off Visible

A manager says, “We improved productivity because the team wrote twice as many lines of code.” What is missing from this claim?

Self-feedback: Lines of code alone say little about delivered value. Ask what happened to quality, cost, time to market, and useful functionality.
