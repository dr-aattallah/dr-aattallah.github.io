Event-Driven & Transformational Architectures

Two very different behaviors need two very different organizing structures: react to events versus transform input into output.

Do not confuse them

Reactive state vs controlled transformation

⚡ Event-Driven

  • Stimulus: external events
  • Order: unpredictable
  • State: central to response
  • External entities: potentially many

⚙️ Transformational

  • Stimulus: input to process
  • Order: processing/control flow
  • State: usually not the central idea
  • Interaction during processing: little or none
Study clarification

Quick classification test

If the important question is “What should happen when event X arrives in state Y?”, think event-driven. If the important question is “What processing sequence turns this input into the required output?”, think transformational.

Memory hook

Event-driven = react. Transformational = process.
