Object-Persistence Framework

Hide database-specific details behind a stable persistence layer.

9of 14
Learning focus

Explain the roles of business objects, DB manager, database-access components, and databases.

  • The source framework includes Business Object A, B, and C, a DB Manager, multiple DB Access components, and DB 1, DB 2, and DB 3.
  • Business objects communicate in the object-oriented implementation language.
  • DB-access components communicate with databases using DBMS-specific languages.
  • The DB Manager stores and retrieves objects from different databases and hides database differences from business objects.
  • The persistence subsystem should focus on storing, retrieving, updating, and efficiently managing persistent data rather than unrelated business processing.
