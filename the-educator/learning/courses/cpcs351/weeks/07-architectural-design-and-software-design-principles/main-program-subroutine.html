Main Program & Subroutine Architecture

Organize a transformation around a controlling main program that delegates work to subroutines.

8of 14
Learning focus

Explain why transformational systems map naturally to main-program/subroutine structures.

  • The source diagram places a main program above a hierarchy/network of subroutines connected by function calls.
  • This style fits systems whose dominant behavior transforms input into output.
  • The main program coordinates overall processing while subroutines perform specialized computational steps.
  • The underlying transformational process may involve sequencing, branching, parallel threads, synchronous behavior, asynchronous behavior, or computation-intensive algorithms.
