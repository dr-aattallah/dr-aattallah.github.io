Topic 02 · Lesson 07

Software Quality Attributes

Understand high quality as a multidimensional profile, not a single score.

7of 9 pages
HookWhat does “high-quality software” mean if two users value different things?

A fast system can be hard to maintain; a reliable system can still be difficult to use.

Learning Focus

Define the five quality attributes emphasized in the lecture and diagnose which attribute is at stake in a scenario.

UsabilityLearn quickly and get the job done easily
EfficiencyAvoid wasting CPU time and memory
ReliabilityDo what is required without failing
MaintainabilityBe easy to change
ReusabilityReuse parts in other projects

Quality Is a Profile, Not a Single Score

The lecture’s core vocabulary is Usability, Efficiency, Reliability, Maintainability, and Reusability. Their relative importance depends on context.

Diagnose the Attribute

A system produces correct results but consumes so much memory that ordinary laptops freeze. Which quality attribute is weakest?

Self-Feedback: Efficiency. Reliability may still be acceptable if results are correct, but inefficient resource use is explicitly the issue.
Common Misconception

“If it works, it is high quality.” Functional correctness matters, but usability, efficiency, reliability, maintainability, and reusability describe different dimensions.
