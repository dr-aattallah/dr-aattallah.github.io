Quality Measurements & Metrics

Turn quality claims into quantitative evidence using measurements and metrics.

6of 9 pages
HookIf a manager says “quality improved,” what evidence would make that statement more than an opinion?

Measurements turn vague claims into evidence—but only if we understand what each metric actually measures.

Learning Focus

Define measurement and metric, identify major metric categories, and interpret representative requirements, design, implementation, and OO metrics.

Measurement vs. Metric

Software measurements are objective, quantitative assessments of software attributes. Metrics are standard measurements. Software quality metrics are standard measurements of software quality.

Design Metrics — Definitions from the Lecture
  • Fan-In: number of modules that call a given module.
  • Fan-Out: number of modules called by a given module.
  • Cohesion: relevance of functions in a module to its core functionality.
  • Coupling: data dependencies among modules.
  • Modularity: high cohesion and low coupling lead to high modularity.
  • Module Design Complexity: integration tests required to integrate a module with subordinate modules.
  • Design Complexity: number of subtrees in structure charts with module M as root.
Implementation & OO Metrics — Complete List

Implementation: Defects/KLOC; pages of documentation/KLOC; comment lines/LOC; cyclomatic complexity—the number of independent control-flow paths in a function (McCabe, 1979).

OO: Weighted methods per class; depth of inheritance tree; number of children; coupling between object classes; response for a class; lack of cohesion in methods.

Common Misconception

“A number is automatically a quality metric.” A metric is useful only when the measured attribute, definition, context, and interpretation are clear.

Interpret, Don’t Just Count

Two modules have equal size. A has high cohesion and low coupling; B has low cohesion and high coupling. Which is more modular?

Self-Feedback: Module A. The lecture explicitly links high cohesion + low coupling with high modularity.
