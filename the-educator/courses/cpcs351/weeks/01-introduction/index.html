Topic 01 · Chapter 1

Introduction to Software Engineering

Before learning how to design software systems, we first need to understand what makes software different, why software engineering exists, and how software is developed throughout its life cycle.

Course Learning Outcome · CLO #1

Explain the concept of a software lifecycle with an example, including the deliverables that are produced from each phase.

The Big Picture

What are we trying to achieve?

Software engineering applies engineering processes and methods to software development. Its overall goal is to significantly improve software productivity and software quality while reducing software cost and time to market.

Software Engineering
↑ Productivity
↑ Quality
↓ Cost
↓ Time to Market

From the original lecture

Key Takeaway Points

01

We begin by understanding the nature of software and the characteristics that make software engineering different from traditional engineering disciplines.

02

Software engineering aims to significantly improve productivity and quality while reducing cost and time to market.

03

Software engineering consists of three interacting tracks of life-cycle activities: software development process, software quality assurance, and software project management.

04

Object-oriented software engineering is a specialization of software engineering that views systems as collections of objects that relate to and interact with one another.

Think Like a Software Engineer

Why do we need engineering for something that is only code?

Imagine a banking application used by millions of customers. Writing code is only one part of the problem. The team must understand requirements, coordinate work, control changes, verify quality, manage risks, and release the system on time. This is where software engineering becomes essential.
