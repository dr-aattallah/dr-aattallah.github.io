GoF Patterns & Singleton

Before GRASP, distinguish situation-specific GoF patterns and see one complete creational example.

2of 8 pages

Two commonly used pattern families

The chapter distinguishes Gang of Four (GoF) patterns from General Responsibility Assignment Software Patterns (GRASP). GoF patterns are situation-specific and are classified as Creational, Structural, or Behavioral.

Creational
Creation of complex or special-purpose objects.
Structural
Structural design problems.
Behavioral
Behavioral or algorithmic design problems.

The GoF catalogue

Creational: Abstract Factory, Builder, Factory Method, Prototype, Singleton. Structural: Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy. Behavioral: Chain of Responsibility, Command, Interpreter, Iterator, Mediator, Memento, Observer, State, Strategy, Template Method, Visitor.

Singleton — problem and solution

Problem: how can a class have only one globally accessible instance? Solution: make its constructor private and provide a public static method. On the first call the instance is created and cached; later calls return the cached instance.

public class Catalog {
  private static Catalog instance;
  private Catalog() { }

  public static Catalog getInstance() {
    if (instance == null)
      instance = new Catalog();
    return instance;
  }
}

The chapter's structural design marks the class with the <<Singleton>> stereotype, a private static instance, private constructor, and static getInstance().

Added examples

A single application-wide configuration object, logging service, or shared registry can illustrate the same intent. The key is not “global variable”; the key is controlled construction and access.
