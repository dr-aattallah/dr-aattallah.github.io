Core lecture

What you need to understand

  • A model is a conceptual representation that lets a team communicate a shared perception of a piece of reality.
  • Domain modeling helps the team understand the application domain and establish common understanding despite different backgrounds.
  • A domain model defines application-domain concepts using classes, attributes, and relationships.
  • For domain modeling, represent the model with a UML class diagram without operations.
