Reviews, Inspections, Walkthroughs, and Peer Review

Static V&V examines software artifacts without executing the program and can detect defects before dynamic testing is possible.

5of 8 pages
Core lecture content Clarification & study aids
Learning focus

Define software quality and explain the role of quality-assurance activities in the software process.

Core lecture

What you need to understand

  • Static verification evaluates artifacts such as requirements, design, and code without execution.
  • Inspection is a structured examination guided by defect criteria or checklists.
  • A walkthrough is led by the developer/author, who explains the product while reviewers question and examine it, often with simple test data.
  • Peer review assigns peers to evaluate an artifact using review questions; reviewers prepare individually and discuss findings.
  • These techniques complement testing rather than replacing it.

Remember

Static reviews find defects in artifacts early; dynamic testing finds failures by executing software.
