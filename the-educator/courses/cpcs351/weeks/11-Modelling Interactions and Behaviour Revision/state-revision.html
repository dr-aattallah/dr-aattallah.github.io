State and event

  • A state represents a discrete, continuous segment of time during which an object's behavior is stable.
  • The object remains in that state until it is stimulated to change by an event.
  • An event is an instant in time that may be significant to the behavior of objects in a class.
  • Events may be written as text strings, for example: Open, Deposit(Amount), Withdraw(Amount), and Close.

Added example — online order

Created → Paid → Packed → Shipped → Delivered. Events such as pay(), pack(), ship(), and confirmDelivery() move the Order between stable states. A cancel() event may be valid only before shipment.

Common confusion

A state diagram follows one object's changing state. A sequence diagram follows messages among multiple participants.
