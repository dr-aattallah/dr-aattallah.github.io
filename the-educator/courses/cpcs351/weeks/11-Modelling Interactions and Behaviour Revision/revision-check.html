Quick retrieval practice

1. You need to show Student, Course, and Registration relationships. Which diagram?
Class diagram — the question is about static structure and relationships.
2. You need to show Student → UI → RegistrationService → Database messages. Which diagram?
Sequence diagram — the focus is ordered interaction/messages.
3. You need to model an Order as New, Paid, Shipped, and Delivered. Which diagram?
State diagram — one object's stable states and event-driven transitions.
4. You need to show payment verification and inventory checking in parallel. Which diagram?
Activity diagram — workflow with concurrency, modeled with fork/join.
5. What is the difference between a merge and a join?
A merge reunites alternative conditional paths; a join synchronizes parallel paths.
6. What does a guard such as [valid PIN] mean?
It is a condition that must be true for that outgoing path to be taken.

One-minute revision map

Structure → Class. User goals → Use Case. Messages → Sequence. Lifetime/events → State. Workflow/parallelism → Activity.

Final checkpoint

Do not memorize diagram names alone. Train yourself to recognize the modeling question hidden inside the scenario.
