Systems & System Engineering

A working software component is only one piece of a real-world system. System Engineering coordinates software, hardware, people, constraints, and interfaces so the whole system can accomplish its mission.

“The key shift is simple: stop looking only at the program. Start looking at the mission, the components, and the connections.”

Core Concept

What is a system?

A system is a set of interrelated components. It can be large or small, simple or complex, natural or man-made, physical or conceptual.

System Engineering

The Control Tower for the whole system

System Engineering applies an engineering process across the entire system life cycle, decomposes the system top-down, and coordinates multidisciplinary teams.

Mentor Insight

Software Engineering is part of System Engineering. When software is embedded in a larger system, engineers must understand what other components expect from the software—and what the software expects from them.

Key Takeaway

A system is made of interrelated components. Systems interact with their environments, exist in hierarchies, and evolve over time. System Engineering coordinates the complete life cycle, decomposes complex systems, and integrates hardware, software, and human subsystems into one mission-oriented whole.

Think Like a Software Engineer

If the control software is perfect but a conveyor sensor sends the wrong signal, where should the failure be investigated?

Think about subsystem boundaries, interfaces, assumptions, responsibilities, and the overall system mission.
