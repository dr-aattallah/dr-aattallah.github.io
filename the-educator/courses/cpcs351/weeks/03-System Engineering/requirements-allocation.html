Requirements Allocation

Allocation assigns each system requirement—or a justified part of it—to the subsystem responsible for satisfying it.

5of 8 pages
Core lecture content Clarification & study aids
Learning focus

Differentiate among the phases of software development and understand software engineering within broader system engineering.

Core lecture

What you need to understand

  • A requirement may be allocated wholly to one subsystem or decomposed across several.
  • Allocation must preserve coverage: every selected system requirement needs an implementation responsibility.
  • Performance requirements often decompose into capacity targets for multiple subsystems.
  • Allocation provides traceability from system need to subsystem responsibility.
