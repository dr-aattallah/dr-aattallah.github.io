Lesson 14

Common Mistakes & Agile Review

Check semantic correctness and model only what helps.

Common mistakes

  • Combining separate calls into one activation.
  • Incorrect nesting of calls.
  • Processing before the triggering event.
  • Too much programming detail.

Agile guidance

  • Understand transactions with users/customers.
  • Write scenarios collaboratively.
  • Skip artifacts when the interaction is already well understood.
  • Use sequence diagrams when visualization adds value.
  • Keep it simple; prototype to remove doubt.

Final self-check

  1. Foreground vs background?
  2. Trivial vs nontrivial?
  3. Scenario/table?
  4. Four translation cases?
  5. Analysis vs design?
  6. Calls, returns, loops, guards, creation?
  7. Messages to responsibilities/methods?
  8. Correct ordering?
