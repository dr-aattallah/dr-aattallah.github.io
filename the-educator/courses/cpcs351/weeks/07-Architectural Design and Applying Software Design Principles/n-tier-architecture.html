N-Tier Architecture

Separate presentation, coordination, business logic, communication, and persistence into clear layers.

6of 14
Learning focus

Explain why N-Tier fits interactive systems and identify its layers.

  • The source view contains a Graphical User Interface layer, Controller layer, Business Objects layer, Network Communication layer, and Database layer.
  • Requests flow through layers rather than allowing every component to depend directly on all others.
  • Presentation handles interaction, controllers coordinate requests, business objects hold domain behavior, network communication handles communication concerns, and database components handle persistence.
  • Layer boundaries support separation of concerns and can reduce change impact when interfaces remain stable.
1Graphical User Interface
2Controller
3Business Objects
4Network Communication
5Database
Remember

N-Tier organizes an interactive system by responsibility layers, not by arbitrary folders.
