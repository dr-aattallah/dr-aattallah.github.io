Final derivation checklist

Before accepting the model

  • The system or subsystem boundary is explicit and meaningful.
  • Actors are external roles, and each important stakeholder role is considered.
  • Candidate names use domain verb–noun language.
  • Every use case passes the four validation questions.
  • Small technical actions remain steps or operations, not top-level goals.
  • The selected abstraction level supports the current decision.
  • Each requirement maps to suitable use cases, and each use case has justification.
  • The diagram remains readable and relationships add real meaning.
